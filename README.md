# Rudra Vaishnav — Interactive Portfolio

Explore the live 3D portfolio: https://rudravaish.github.io/

Walk around a compact mountain overlook to discover my experience, projects, skills, current work, and interests beyond code.

## Controls

- **W A S D** — move
- **Drag** — look around
- **Shift** — run
- **Space** — jump
- **E** — explore a nearby stop
- **V** — view the character
- **F** — face detail while viewing the character

You can also use the destination buttons to take a short walk to each section.

Built with Three.js and Vite. The character and animations use Quaternius’s Universal Base Characters and Universal Animation Library (CC0 1.0), customized for this portfolio.
